# Explainable AI Text Detector

> Final Project for **CSC 7644: Applied LLM Development**

A web application that detects whether a piece of text was written by a human or generated by AI. It goes beyond a simple score — it highlights exactly which sentences sound most AI-generated, explains the reasoning in plain English, suggests a human-style rewrite, and then lets you re-analyze the rewrite to see if it actually improved.

---

## Key Features

- **AI Detection** — Classifies text as AI-generated or Human-written using a RoBERTa-based model with a tuned confidence threshold
- **Sentence-level Highlighting** — Scores each sentence individually and highlights the most AI-sounding ones directly in the UI
- **Plain English Explanation** — Uses an LLM to explain in simple terms why the text may appear AI-generated
- **Human-style Rewrite Suggestion** — Rewrites the text to sound more natural and conversational
- **Rewrite Feedback Loop** — Re-analyzes the rewrite and compares its score to the original, showing whether the rewrite actually helped
- **Clean UI** — Built with Streamlit, styled with a professional purple and gold theme

## Tech Stack and Architecture

### Models and APIs
| Component | Technology |
|-----------|-----------|
| AI Detection | `roberta-base-openai-detector` (HuggingFace Transformers) |
| Explanation | OpenAI GPT-4o-mini via OpenAI API |
| Rewrite | OpenAI GPT-4o-mini via OpenAI API |
| Frontend | Streamlit |

### Architecture Overview

```
User Input (text)
       │
       ▼
┌─────────────────┐
│   detector.py   │  ← RoBERTa model scores full text + each sentence
└────────┬────────┘
         │ score + sentence scores
         ▼
┌─────────────────┐
│  explainer.py   │  ← OpenAI GPT-4o-mini explains the score
└────────┬────────┘
         │ explanation
         ▼
┌─────────────────┐
│   rewriter.py   │  ← OpenAI GPT-4o-mini rewrites to sound human
└────────┬────────┘
         │ rewrite suggestion
         ▼
┌─────────────────┐
│     app.py      │  ← Streamlit renders all results + feedback loop
└─────────────────┘
```

### Main Components
- **`detector.py`** — Loads and runs the RoBERTa classification model. Scores the full text and individual sentences. Threshold set to 0.35 for better sensitivity to modern AI writing.
- **`explainer.py`** — Calls OpenAI API with a carefully crafted prompt to explain in beginner-friendly language why the text may be AI-generated.
- **`rewriter.py`** — Calls OpenAI API with strict instructions to produce a genuinely human-sounding rewrite — avoiding formal jargon, using contractions, and writing conversationally.
- **`app.py`** — Streamlit front end that ties all modules together, renders the UI, and manages session state for the feedback loop.
- **`evaluate.py`** — Offline evaluation script that runs the detector over a labeled CSV dataset and prints accuracy, precision, recall, F1, and a confusion matrix.
- **`plot_results.py`** — Generates a bar chart of evaluation metrics and saves it as a PNG.

## Setup Instructions

### Prerequisites
- Python 3.9 or higher
- pip
- An OpenAI API key ([get one here](https://platform.openai.com/api-keys))
- ~500MB disk space for the RoBERTa model (downloaded automatically on first run)

### 1. Clone the Repository

```bash
git clone https://github.com/rubaiyat-sholi/csc7644-final-project-Sholi.git
cd csc7644-final-project-Sholi
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Copy the example environment file and fill in your API key:

```bash
cp .env.example .env
```

Open `.env` and set your key:

```
OPENAI_API_KEY=your_openai_api_key_here
```

### 4. First Run — Model Download

On the first run, the RoBERTa model (~500MB) will be downloaded automatically from HuggingFace and cached locally. This only happens once.

---

## Running the Application

```bash
streamlit run app.py
```

Then open your browser and go to:

```
http://localhost:8501
```

### How to Use
1. Paste any text into the input box (essay, email, article, etc.)
2. Click **🚀 Analyze Text**
3. Review:
   - **AI Score** and label (AI-generated / Human-written)
   - **Sentence Analysis** — highlighted sentences showing which parts sound most AI-generated
   - **Explanation** — plain English reasoning
   - **Rewrite Suggestion** — a more human-sounding version
4. Click **🔁 Re-analyze Rewrite** to compare the rewrite score against the original

## Known Limitations

- The detector uses `roberta-base-openai-detector`, which was trained on GPT-2 era text (2019). It works well for most cases but may underestimate newer GPT-4 style writing, particularly formal corporate or academic text.
- The sample evaluation dataset contains only 8 samples. Evaluation metrics should be interpreted as indicative rather than statistically significant.
- Detection threshold is set to 0.35 (rather than the default 0.5) to improve sensitivity to modern AI writing patterns.
